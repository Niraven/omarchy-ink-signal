# Extras

All extras are optional. The installer does not enable them.

## Day/night switch

```bash
./extras/day-night.sh auto     # 07:00–19:00 light, otherwise night
./extras/day-night.sh light
./extras/day-night.sh night
```

Override the boundary with `INK_SIGNAL_DAY_START` and `INK_SIGNAL_NIGHT_START` (24-hour).

Schedule it with a systemd user timer:

```ini
# ~/.config/systemd/user/ink-signal-theme.service
[Unit]
Description=Ink Signal day/night theme

[Service]
Type=oneshot
ExecStart=%h/path/to/omarchy-ink-signal/extras/day-night.sh auto
```

```ini
# ~/.config/systemd/user/ink-signal-theme.timer
[Unit]
Description=Switch Ink Signal twice a day

[Timer]
OnCalendar=*-*-* 07,19:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now ink-signal-theme.timer
```

## Wallpaper cycle

```bash
./extras/cycle-wallpaper.sh next
./extras/cycle-wallpaper.sh light
./extras/cycle-wallpaper.sh night
```

Bind it in Hyprland if you want a key:

```lua
o.bind("SUPER, B", "Cycle Ink Signal wallpaper", "~/.local/bin/ink-signal-cycle next")
```

Install the helper first:

```bash
./install.sh --helpers
# or: install -Dm755 extras/cycle-wallpaper.sh ~/.local/bin/ink-signal-cycle
```

## Typography

See [TYPOGRAPHY.md](TYPOGRAPHY.md). The short version:

```bash
./install.sh --typography                 # Obsidian snippet
./extras/gtk-typography.sh apply          # GTK font stack
./extras/gtk-typography.sh restore        # undo
```

## GTK accent

Back up `~/.config/gtk-4.0/gtk.css` and `~/.config/gtk-3.0/gtk.css`, then append `extras/gtk-accent.css`. This changes accent and selection colors only; it does not replace the widget theme.

## Menu entries

Merge `extras/omarchy-menu.jsonc` into `~/.config/omarchy/extensions/omarchy-menu.jsonc`. The snippet adds **Ink Signal → Light / Night / Next wallpaper**.

## Lock screen

The theme's `shell.lock.toml` is generated by Omarchy at apply time. No extra file is needed; test it with your usual lock command.
